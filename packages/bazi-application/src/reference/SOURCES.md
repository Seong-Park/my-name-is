# 대한민국 출생지역 카탈로그

- 원본: `기상청41_단기예보 조회서비스_오픈API활용가이드_2607.zip`, 그 안의 `격자_위경도(2607).xlsx`. 시트의 업데이트 기준일은 **2026-07-01**. 수집일은 **2026-09-23**.
- [직접 다운로드](https://www.data.go.kr/cmm/cmm/fileDownload.do?atchFileId=FILE_000000003671875&fileDetailSn=1). 원본 ZIP은 `source/kma-2607.zip`에 보존한다.
- SHA-256: `07f53cd9d6d6512bce6ef870d54cb740046a0a949896e6855caecf739fb8842e`.
- 포털에 표시된 이용허락: **공공누리 제1유형(출처표시)**. 본 문서가 기상청 출처와 가공 내역을 명시한다. 독자적인 측량 결과나 기상청의 서비스 보증을 의미하지 않는다.
- 서비스 저장 버전: `kma-2026-07-01-v1`. 공식 자료의 날짜와 애플리케이션 가공 버전을 구분한다.

## 가공 규칙

`source/generate.py`가 ZIP의 XLSX를 읽어 `locations-data.ts`를 재생성한다. Python `openpyxl`은 오프라인 데이터 생성에만 필요하며 런타임 의존성이 아니다.

1. `구분=kor`인 행에서 1단계 시·도와 2단계 시·군·구를 사용한다. 3단계 읍·면·동은 제외한다.
2. 상위 시·도는 코드 끝 8자리가 `0`인 행으로 한정한다. 기상 지점인 이어도는 행정 시·도가 아니므로 제외한다.
3. 원본 행정구역코드를 문자열로 보존하고 서비스 ID에 `KR-` 접두어만 붙인다. 임의 순번이나 명칭 해시를 쓰지 않는다. 종로구 예: `KR-1111000000`.
4. 경도·위도는 XLSX의 소수도 열을 그대로 사용한다. 예보 격자 X/Y를 경위도로 오해하거나 새로 지오코딩하지 않는다.
5. 세종은 원본의 2단계 세종특별자치시 행을 선택 항목으로 유지하며 전체 표시명에서 동일 명칭을 중복하지 않는다.
6. 대한민국 카탈로그의 IANA 시간대는 `Asia/Seoul`로 지정한다. 원본 XLSX에 시간대 열은 없다. [IANA tzdb zone1970.tab](https://data.iana.org/time-zones/tzdb/zone1970.tab)의 KR 항목을 기준으로 한다. 출생일의 UTC 오프셋이나 DST를 이 카탈로그에서 계산하지 않는다.

## 현재 행정구역에 대한 검증

원본에서 **16개 시·도와 256개 시·군·구 수준의 선택 항목**이 추출된다. 이 수는 자치단체 총수와 다르다. 일반구(수원시장안구 등)도 포함하며 시 아래 일반구가 있는 경우 원본의 해당 일반구를 선택한다.

- 전남광주통합특별시의 2026-07-01 출범은 [행정안전부 보도자료](https://www.mois.go.kr/frt/bbs/type010/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000008&nttId=124745)와 [광주시 공식 안내](https://newscms.gwangju.go.kr/gallery.es?act=view&bid=0009&list_no=5311&mid=a50102000000&obid=0009&tab_type=category)로 교차 확인했다. 따라서 과거의 17개 시·도를 상수로 강제하지 않는다.
- 인천의 제물포구·영종구·서해구·검단구를 포함하는 개편은 [인천시 공식 보도자료](https://www.incheon.go.kr/IC010205/view?curPage=1&repSeq=DOM_0000000014871020)로 교차 확인했다. 종전 중구·동구·서구 코드를 신규 지역 코드로 묵시 변환하지 않는다.

## 한계·사용 정책

- 좌표는 **지역 대표점**이다. 출생 병원·주소의 정확한 좌표, 지역 경계 중심, 구청 건물 위치라고 보증하지 않는다. 화면에서 대표 좌표임을 설명한다.
- 이는 2026-07-01의 정적 스냅샷이다. 그 이후 모든 변경을 실시간 반영한다고 주장하지 않는다. 갱신할 때 새 버전으로 등록하며 이미 저장된 프로필의 명칭·좌표·버전 스냅샷을 덮어쓰지 않는다.
- 과거 출생지의 역사적 명칭·경계 조회는 이번 범위 밖이다. 사용자는 현재 명칭으로 해당 장소를 선택한다. 분할·통합된 구역의 과거 코드를 자동으로 추정하지 않는다.
- 외국·상세 주소·읍면동 입력은 지원하지 않는다. 카탈로그는 사주·진태양시 계산을 수행하지 않으며 기존 `core-engine`을 import하지 않는다.
