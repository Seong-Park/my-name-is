# 겨울 목·화 조건군의 역할 보존 검토

2026-10-03 · 검토자 Codex 연구 에이전트(AI). 앱·출생 mock·LLM 호출은 변경하지 않았다. [이전 검토](2026-10-01-balance-adoption-review.md)의 두 빈칸만 조사했다. 고전의 명리 해석을 서비스 모델로 옮기는 검토이며 효과의 실증이나 전문가 검수가 아니다.

## 판단

**아래의 닫힌 조건군을 출처에 근거한 제한적 서비스 해석으로 채택하는 것을 권고한다.** 두 번째 구성을 그대로 적은 문헌을 찾지 못했다는 이유만으로 계속 보류하는 것은 과도하다. 이번에 추가로 확인한 일반 역할·위치 규칙으로 기대값을 코드와 독립적으로 설명할 수 있다. 다만 두 구성 모두 원문에 직접 실린 정답이라고 표시하면 안 된다. 구현·테스트를 확인하지 않았으므로 실행 코드의 `validated` 승격 자체를 완료한 문서는 아니다.

## 직접 대조한 근거

- S1: [《子平真詮評註》「論用神配氣候得失」](https://www.8bei8.com/book/zipingzhenquanpingzhu_16.html)의 徐注. 겨울 목의 재관을 취용하지 않는 이유와 `庚寅 戊子 甲寅 丙寅`의 시간 화가 설기·조후를 담당한다고 설명한다. 해당 전사의 검색 추출과 기존 직접 열람 기록을 대조했다. 이번 본문 재열기는 일시 실패했다. 이 사실을 새 영인본 확인으로 기록하지 않는다.
- S2: [「論生克先後分吉凶」](https://www.8bei8.com/book/zipingzhenquanpingzhu_22.html), 이번 본문 직접 열람. 인성이 재성에 실제 손상되는 조건을 인약·재중, 일간의 인성 필요, 비겁의 구제 부재로 한정한다(徐注, 인격 단락). 따라서 재성 글자가 있다는 이유만으로 인성 손상이라고 하지 않는다. 뒤의 `癸酉 甲子 丁卯 丙午` 해설에서는 지지 중간의 목이 수화 연결을 이루어 충돌을 해소하는 작용을 명시한다. 위치에 따라 기능이 달라지는 다른 사례도 함께 읽었으므로 모든 원격 생극을 무효로 취급하지 않는다.
- S3: [「論用神」](https://8bei8.com/book/zipingzhenquanpingzhu_10.html), 이번 본문 직접 열람. 병약은 필요한 부·억 기능이 훼손되는 경우, 통관은 두 기운의 실제 대치와 균평을 전제로 한다. 원국에 해결자가 없다는 것이 비적용은 아니라는 문장도 보존한다. 다섯 방법 정의는 《評註》 전승층으로 귀속하고 沈氏 원문이라고 단정하지 않는다.
- S4: [《淵海子平評註》 지지 관계 표](https://www.8bei8.com/book/yuanhaiziping_11.html)의 자형 표지는 辰午酉亥다. 저장소의 채택된 P1 관계표와도 대조한다. 寅 반복을 자형으로 추가하는 근거가 아니다. 寅巳申 형에 필요한 巳·申은 이 범위에 없다.

S2 열람 재현 위치: 제목 「论生克先后分吉凶」의 인격 徐注에서 `必也印轻财重`를 검색한다. 이번 web.open 출력 L119에서 전후 조건을 확인했다. 지지 연결은 같은 페이지 끝 부분의 명식 `癸酉 甲子 丁卯 丙午` 다음 해설에서 `子午之间隔以卯木`를 검색한다(L315). 이어지는 충돌 대비 명식 해설은 L333이다. 최초 www 없는 URL 시도는 timeout이었지만, 이후 **www 있는 위 정확한 URL의 open은 405행 본문으로 성공**했다. 검색 snippet만으로 이 두 문단을 판정한 것이 아니다.

## 채택 범위와 추론

이전 후보의 조건을 **늘리지 않는다**: 완전한 실제 원국, 甲일간·子월지, 연·일·시지 寅, 丙시천간 한 번, 나머지 천간은 甲/戊/庚, 庚은 연간에만 한 번, 戊 노출 한 번 이하. 실제 간지 연동을 만족하는 내부 구성은 문헌 원형과 `戊寅 甲子 甲寅 丙寅`이다. 생일 목록이나 전체 팔자 equality가 아니라 이 입력 전제를 평가한다.

| 항목 | 코드 이전 기대 판단과 이유 | 근거 성격 |
| --- | --- | --- |
| 강약·억부 | 신강, 화 설기. 문헌 원형의 세 寅·일간·계절을 보존하고, 비취용 庚 대신 월간 甲이 더해진다. 이를 일간 약화로 뒤집는 새 제어·뿌리 손상은 없다 | 원형은 직접 사례, 변경형은 역할 보존 추론. 수량 점수나 모든 甲增의 보편 단조 법칙이 아님 |
| 조후 | 화 목표. 子 계절, 寅 속 화와 丙寅시가 그대로이며 추가 수간·한습 지지·화합거가 없다 | S1의 일반 화 기능에 근거한 범위 내 추론 |
| 병약 | 별도 제거 대상 비적용. 丙 기능을 훼손하는 새 수간·辛합·화근 충이 없다. 戊가 연간으로 옮겨도 일·시의 목→화 연결이 바뀌지 않으며, 월간 甲은 인성을 재성으로부터 더 노출시키는 변경이 아니다. S2의 인약재중·구제부재 전제도 성립하지 않는다 | S1의 청순 화, S2의 실제 손상 전제를 적용한 서비스 판정. 원문에 병약 음성이라는 API 문구가 있다는 주장이 아님 |
| 水火 통관 | 별도 통관 목표 비적용. 지지 수→목→화 경로가 원형과 동일하고, 중간 목을 제거하거나 화를 수에 직접 노출하는 변경이 없다. 원국에 목이 없어서 해결자를 기다리는 경우와 다르다 | S2의 중간 목에 의한 연결을 좁게 적용. 이미 기능하는 연결 때문에 추가 독립 목표가 없다는 의미 |
| 木土 통관 | 별도 통관 목표 비적용. 원형에서 토는 겨울의 비취용 재성이며 변경형은 토의 수·뿌리·계절을 강화하지 않는다. 강한 목의 세 뿌리를 그대로 두고 甲을 추가한다. 따라서 약한 토가 목과 균평하게 대치하는 쪽으로 전환됐다고 판단하지 않는다 | S1의 재성 역할 + S3의 균평 전제에 근거한 비교 추론. 寅 속 戊를 삭제하거나 土 존재 자체를 무시하지 않음 |
| 金木 및 土水 대치 | 金은 원형의 무근·비취용 범위이거나 아예 없다. 토수는 S2의 실제 재파인 전제를 만족하지 않는다 | 해당 조건군 전용. 다른 계절·지지로 확대 금지 |

반복 寅은 P1 표에 자형이 없으며, 子·寅만으로 육합·삼합·방합 완성이나 충·형·파·해를 새로 구성하지 않는다. 암합·허자·가상 巳 호출은 이 서비스 조건군에서 새 효과로 도입하지 않는다. 원문의 귀천·수명·재산 결과도 채택하지 않는다.

## 기대 사례와 제외 경계

- 문헌 양성: `庚寅 戊子 甲寅 丙寅` → 위 네 방법 판단, 최종 화. 문헌의 설기·조후는 직접 기대값이고 통관·병약 음성은 위 원칙 적용 결과다.
- 독립 서비스 기대 사례: `戊寅 甲子 甲寅 丙寅` → 같은 판단. **독립된 역사 문헌 사례가 아니라 코드 이전의 출처 기반 추론 사례**다. 이 명칭을 테스트·보고서에 유지한다.
- 제외 검사: 子월 불일치, 寅 한 곳 변경, 시주 변경, 수 천간·辛·추가 화·추가 戊·다른 위치 庚, 불완전/후보 원국은 이 규칙으로 확정하지 않는다. 제외 결과는 `unknown/outside_scope`이지 반대 오행 정답이나 일반 비적용이 아니다.
- 관계 반례: S2의 목 중간 연결 사례와, 이어지는 `辛卯 丁酉 戊子 戊午`에서 실제 충으로 기능이 깨지는 설명을 경계 검토에 사용한다. 이를 겨울 목 후보의 다른 강약 정답으로 복제하지 않는다.

정확히 같은 여덟 글자의 추가 원문, 모든 학파의 음성 증명, 전문가 도장을 필수로 요구하지 않는다. 반면 위 서비스 추론을 전통 전체의 유일한 정답으로 승격하지도 않는다. 이 문서의 권고는 좁은 모델·정직한 출처 표시·범위 밖 보류를 함께 유지하는 경우에 한한다. 화 이외 허용/비권장 오행이나 최강 오행까지 여기서 자동 결정하지 않는다.
