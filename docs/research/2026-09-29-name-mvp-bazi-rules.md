# 「나의 이름은」 MVP: 균형 방향과 구조상 최강 오행의 규칙 조사

조사일: 2026-09-29. **상태: 연구·채택 제안. 구현 규칙이나 전문가 검증의 승인 기록이 아니다.** 고전 원문의 웹 전사를 직접 확인했으며 영인본 전체를 교감하지 않았다. 아래 고전 자료는 명리 체계 내부의 문헌 근거이지 이름이 삶의 결과를 바꾼다는 실증 근거가 아니다.

## 결론과 경계

1. **균형형**은 이미 승인된 [ADR-006](../references/mylife/docs/bazi/adr/ADR-006-yongshin-priority.md)에 따라 조후·억부·통관·병약의 *검증된* 적용 규칙을 독립 평가하고, 양립 가능한 목표를 선택할 근거가 있을 때만 오행 방향을 확정한다. 일간 신강신약이나 계절만으로 용신을 단정하지 않는다. 방법 간 충돌 또는 선택 규칙 부재는 보류한다. 이 네 방법의 세부 규칙과 선택 규칙은 아직 미완료다. [ENGINE_SPEC, ADR-006 계약](../references/mylife/docs/bazi/ENGINE_SPEC.md#adr-006-방법별-분석과-균형-결과-조정), [구현 추적 M7](../references/mylife/docs/bazi/IMPLEMENTATION_TRACKER.md#m7--용신희신기신).
2. **극대화형**은 다섯 오행 각각의 계절 상태, 원국 내 뿌리와 드러남, 생조와 제약을 별도 관측한 뒤 *상호 비교가 검증된 경우에만* 최강 집합을 만든다. 일간 하나의 `strengthClass`나 글자 수를 다섯 오행 순위로 복사할 수 없다. 출처는 이 관측 축을 뒷받침하지만 다섯 오행의 보편적 총점·가중치·동률 판정법은 제공하지 않는다. 따라서 순위 판정 규칙을 만들고 기준 명식으로 검증하기 전에는 추천을 보류한다. [제품 초안 §3](../specs/2026-09-29-my-name-is-mvp-design.md#3-확정된-추천-원칙), [ADR-004](../references/mylife/docs/bazi/adr/ADR-004-strength-model.md).
3. 구조상 최강을 **과도해도 더 강화**하고, 공동 최강일 때 **화 → 수 → 목 → 토 → 금**을 적용하는 것은 [제품에서 승인한 사고 실험의 규칙](../specs/2026-09-29-my-name-is-mvp-design.md#3-확정된-추천-원칙)이다. 전통적인 길한 용신 선택, 오행의 보편적 우열 또는 균형형보다 좋다는 판단으로 표시하지 않는다. 조사한 고전은 오히려 지나침에 대한 제어 가능성을 언급한다.

## 권고하는 제한된 채택안

| 단계 | 채택 제안 | 확정 전에 필요한 근거 |
| --- | --- | --- |
| 원국 관측 | M3에서 확정된 원국, 또는 후속 후보 생성기가 산출한 실제 가능한 원국별로 월지·계절, 천간 노출, 네 지지의 지장간/role, 오행 간 생극과 지원·제약, 발견된 합충과 누락을 **오행별**로 남긴다. 지장간은 membership이며 획일적 분량이 아니다. | [M4·M5](../references/mylife/docs/bazi/IMPLEMENTATION_TRACKER.md#m4--오행지장간십성합충) 구현과 출처·위치가 붙은 관측 검증. 원국의 미확정 필드를 그대로 전파. |
| 계절 상태 | 출처와 버전이 명시된 旺·相·休·囚·死 대응표를 후보 관측으로 삼는다. 계절은 출생 월주의 절기 판정에서 가져온다. | 월지별 표, 토의 계절 처리, 절입 전후, 월중 사령을 도입할지의 선택을 독립 fixture로 검증. 계절 상태를 전체 강도 등급으로 자동 승격하지 않기. |
| 다섯 오행 비교 | 각 오행의 관측 근거를 나란히 보존하고, **승인된 쌍별 비교 규칙**으로 한 오행이 나머지 넷보다 강하거나, 최강 집합의 각 원소가 집합 밖 오행보다 강하면서 집합 안은 진정한 동률일 때만 최강 집합을 확정한다. 집합 밖 오행끼리의 순위는 필요 없다. 비교 불능은 동률이 아니다. | 계절·뿌리·노출·생조·제약 사이의 우선순위, 상충 처리, 공동 최강의 동치 조건을 전문가 검토와 독립 명식 fixture로 명시. 임의 100점, 팔자 개수, `strengthClass` 재사용 금지. |
| 극대화 목표 | 확정된 최강 집합이 1개면 그대로, 복수 **확정 동률**이면 승인된 화→수→목→토→금 순서에서 첫 오행을 택한다. 과도 여부는 별도 근거로 기록하되 목표를 뒤집지 않는다. | 동률과 보류가 구별되는 비교 결과. 제품 규칙임을 UI·결과 근거에 표시. |
| 균형 목표 | [ADR-006](../references/mylife/docs/bazi/adr/ADR-006-yongshin-priority.md)의 방법별 결과와 `resolutionStatus`를 보존한다. 검증된 최종 선택 규칙이 한 목표를 확정했을 때만 이름 추천에 넘긴다. | M6의 확정 강약, M7 방법별 적용조건·충돌 해결·선택 규칙. `aligned`만으로 `resolved`를 만들지 않기. |
| 불확실성 | 두 유형의 확정 가능 여부를 각각 판단한다. 출생시각 미상 또는 역법 후보가 여럿이면 각 **실제로 가능한 완전한 원국**에서 같은 목표 오행이 확정되어야 해당 유형을 제공한다. 하나라도 미판정이거나 목표가 갈리면 그 유형은 보류한다. | 시간 구간·절입·일계·진태양시를 함께 적용한 원국 후보 생성과 범위 완전성 검증이 먼저 필요하다. 각 기둥의 후보를 독립적으로 임의 조합하거나 12개 임의 시각만 대입하면 실제로 불가능한 원국을 만들거나 가능한 원국을 빠뜨릴 수 있다. 동률 우선순위는 각 원국 안의 진정한 동률에만 적용한다. |

이 표는 완성된 계산 알고리즘이 아니다. 현재 채택할 수 있는 것은 **관측·근거·보류 계약**과 제품의 조건부 선택 순서다. 비교 규칙과 검증이 비어 있는 동안 극대화형 목표를 생성하면, ‘구조적 B 방식’이라는 약속을 충족하지 못한다. 균형형도 M7의 주용신 선택이 완성되기 전에는 방향을 확정할 수 없다. [README 현황](../references/mylife/docs/bazi/README.md), [M4~M7 추적](../references/mylife/docs/bazi/IMPLEMENTATION_TRACKER.md#m4--오행지장간십성합충), [MVP 초안 §8](../specs/2026-09-29-my-name-is-mvp-design.md#8-최종-명세-전에-남은-결정과-검증).

특히 현행 [M3 계산 타입](../../packages/bazi-domain/src/chart/calculation.ts)은 시각 미상에서 `hour: unavailable`과 기둥별 `FieldResolution`을 반환한다. **상호 연동된 완전 원국 후보 집합은 제공하지 않는다.** 따라서 ‘시간 미상 후보의 합의’는 별도의 후보 생성·범위 검증 없이는 구현할 수 없다. 기존 [`core-engine` 용신 코드](https://github.com/Seong-Park/mylife/blob/9c3566c61ae18c1c0884d07dff8aa48657bbd58a/packages/core-engine/src/saju/yongshin.ts)의 겨울→火 및 고정 점수·임계값도 [ADR-004](../references/mylife/docs/bazi/adr/ADR-004-strength-model.md)·[ADR-006](../references/mylife/docs/bazi/adr/ADR-006-yongshin-priority.md)의 승인 범위와 달라 새 서비스의 지름길로 재사용할 수 없다.

## 작성해야 할 독립 검증 fixture

명식은 M3가 확정한 **실제 가능한 사주**에서 뽑고 입력 지역·출생시각·규칙 버전·기둥 네 개를 보존한다. 기존 [M3 독립 100건 fixture](../../packages/bazi-engine/tests/fixtures/reference-cases.json)는 기둥 기대값의 출발점이지 아래 강약·용신의 전문가 정답은 아니다. 각 fixture의 예상 관측과 최종 판정은 구현 출력에서 복사하지 않고 별도로 검토해야 한다.

| fixture 조건 | 최소 기대 확인 |
| --- | --- |
| 같은 글자별 오행 개수이나 봄·가을 월령이 다른 두 원국 | 계절 프로필 변화와 다른 강도 비교 근거. 원시 개수만으로 동일 결과를 강제하지 않음. |
| 봄 목이 계절을 얻었지만 금의 노출·뿌리·제약이 많은 명식, 가을 목이 실령했지만 寅·卯에 깊게 뿌리내린 명식 | 월령과 뿌리·제약의 근거를 따로 보존하고, 검증되지 않은 우선순위이면 최강 보류. 《子平真詮》 「六」의 반례 취지에 부합하는지 전문가 확인. |
| 일간의 오행과 구조상 최강 후보가 다른 명식 | 일간 `strengthClass`와 오행별 비교 결과를 독립 산출. |
| 특정 오행이 과도하다고 균형 방법이 판단하지만 그 오행이 구조상 단독 최강인 명식 | 균형형과 극대화형 목표가 달라도 양쪽 근거 유지. 극대화형의 과도 부담 표시. |
