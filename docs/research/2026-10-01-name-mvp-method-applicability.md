# 「나의 이름은」 통관·병약 적용 경계 문헌 조사

조사일: 2026-10-01. **성립 전제, 원국에 해결자가 없는 경우, 특정 규칙의 비적용을 구별하는 자료를 확보했다. 네 방법의 전체 판정을 닫는 실행 규칙이나 승인은 아니다.** 다른 연구 파일·앱은 변경하지 않았다.

**원문/평주를 섞지 않는다.** S2는 다섯 분류 부분에 웹 UI의 「原文」을 붙이고, 뒤에 별도의 「林注」도 삽입한다. 같은 사이트의 ‘무주해본’에도 다섯 분류가 실려 있어 이 라벨만으로 沈氏 원문임을 입증할 수 없다. S3의 해당 절은 월령·순역 설명 다음에 바로 각 취용 관계가 이어지고 다섯 분류가 없다. S5는 표지에서 沈氏 원저·徐氏 평주를 구분하지만 웹 추출은 서체 차이를 보존하지 않는다. 따라서 본 문서에서는 **다섯 분류를 《評註》 전승층 자료로만 기록하고 沈氏 원문으로 귀속하지 않는다.** 초기 영인본에서 평주 경계를 교감한 상태도 아니다.

## 2. 통관: 성립·부재·특정 비적용은 다르다

통관 행의 출처는 S2·S5 「(五)通關」 및 S4 「坎離論」 끝 謹按이다. TG-NA-01은 [기존 조건표](2026-09-30-name-mvp-bazi-condition-tables.md)의 범위를 새로운 별본 전사에서도 확인한 것이며 새 일반 규칙을 발견했다고 표시하지 않는다. S4의 결락 보충층 문구를 《滴天髓》 전체 판본의 공통 원문으로 합치지 않는다.

## 4. 구현에 전달할 정확한 범위

이번 조사로 필요한 상태 구분은 더 분명해졌다. **적용 이유가 성립하지만 해결자가 없는 경우**를 `not_applicable`로 반환하면 위 양성 문헌과 충돌한다. 반대로 실제 상애가 없다는 독립 판정이 있는 재인 규칙은 그 규칙에 한해 제외할 근거가 있다. 어느 규칙도 맞지 않았다는 검색 결과만으로 방법 전체를 제외하지 않는다.

아직 입력만으로 판정할 수 없는 전제는 (1) 양측 기운의 대치·균평, (2) 실제 기능 손상, (3) 중화·무손상, (4) 특수격·격국 변화다. 이 전제의 결과를 `true`로 외부에서 주입하거나 미검증 조건표로 채운 뒤 문헌 검증이라고 부르지 않는다. 문헌은 이를 진단 전제로 사용하며 모든 경계를 닫아 주지 않는다.

S1의 무병 서술을 근거로 ‘水가 없으면 병 없음’ 등의 새 명제를 만들 수 없다. S2의 TG 양성 명식에서 한 글자를 바꾼 가공 원국을 독립 음성 정답으로 사용할 수도 없다. 원국의 실제 가능한 달력 연결과 변형 후 기대값은 별도 조사 대상이다.

납품 상태: **직접 열람·짧은 인용·적용/부재/특정 제외의 구분을 기록**했다. 영인 판본 교감, 방법 전체 음성 완전 명식, 네 방법 동시 평가, 서비스 강약 등급·최강 비교·이름 오행 투영은 완료하지 않았다. 기존 계약을 변경하거나 실제 추천을 활성화하지 않았다.
