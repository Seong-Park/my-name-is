# 한자 확장 조사 — 확보 원본과 추가 5쌍

조사일: 2026-09-30. 검토자: Codex 연구 에이전트(AI). 기존 21고유자 자료를 수정하지 않은 추가 조사다. **200고유자·오행별 40자 완료 자료가 아니다.** 아래 5자는 자형–독음·뜻과 채택 정책에 따른 원획 전사 메타데이터를 검토했다. 원본 스캔 교감은 하지 않았다.

## 확보한 자료

[Unicode KRName 등록 페이지](https://unicode.org/ivd/krname/)는 법원의 인명용 한자 조회와 **법원 표의 보관 PDF**를 연결한다. [보관 PDF](https://unicode.org/ivd/krname/hanja.pdf)를 실제 다운로드했다. 법원 서버에서 직접 받은 파일은 아니다.

- 보관 파일: [2024-06-11-hanja-unicode-hosted.pdf](../../.cache/name-hanja-research/2024-06-11-hanja-unicode-hosted.pdf). 절대경로 `.cache/name-hanja-research/2024-06-11-hanja-unicode-hosted.pdf`.
- 크기 23,984,101 bytes, 63페이지. SHA256 `A2B3C6F2E16614225CD01A4CFE561E2516B67A5E03F249A66B64AEA9414A0C97`.
- PDF 1페이지는 2024-05-23 대법원 보도자료로, 1,070자 추가 및 2024-06-11 시행, 총 9,389자를 명시한다. PDF 10페이지 표 머리에도 2024-06-11 시행을 시각 확인했다. 법령 개정일 표기 차이(보도자료/표의 5월 23일, 법령정보센터 공포 5월 30일)를 임의로 통일하지 않는다.
- 기존 21자의 실시간 법원 조회와 달리 아래 확인은 **2024 판본 보관 PDF의 시각 확인**이다. 2026년 현행 판본과의 전수 차이 검사는 하지 않았다.
- pypdf `extract_text(extraction_mode='layout')`로 본문 표의 한자와 한글이 대부분 추출되지 않았다. 일반 텍스트 추출의 실패이지 법원 표 자체 미확보가 아니다. Poppler로 페이지를 렌더링하여 아래 자형과 음을 대조했다. 공식 Unicode 코드포인트 기계 매핑은 미확보다.
- PDF와 렌더링은 저장소의 기존 무시 경로 `.cache/name-hanja-research/`에 보관했다. Git에 포함되지 않으므로 다른 환경에서는 URL·해시로 재확보해야 한다.

## 추가 5자 원획 전사 메타데이터

채택 정책 `kangxi-tongwen-entry-v1`에 따라 康熙字典網上版 개별 항목의 부수획·부외획·총획과 同文書局本 위치를 직접 확인했다. **전사 메타데이터 수준이며 스캔 교감은 false**다. 사이트가 제시한 武英殿本 위치도 기록했지만 이를 독립적인 두 판본 교감이라고 표현하지 않는다.

堉의 교육부 일반 총획은 10획이지만 이번 강희 항목 총획은 11획이다. 일반 총획을 복사하지 않고 정책에 맞는 값을 채택했다. [기존 21자 원획 조사](2026-09-30-name-mvp-original-strokes.json)와 합치면 **26고유자**의 전사 메타데이터를 확인한 상태다. 이는 추천 적격 26자 또는 원본 스캔 교감 26자를 뜻하지 않는다.

## 200자 확장에 사용할 수 있는 보조 자료와 한계

[UAX #38 kKoreanName](https://www.unicode.org/reports/tr38/#kKoreanName)는 **독음과 무관한** 인명용 목록 최초 수록 연도다. 교육용 1,800자는 kKoreanEducationHanja로 따로 표시한다. 문서는 2022년 40자·2024년 1,070자 추가를 반영할 데이터가 없다고 명시한다. 따라서 kKoreanName 부재를 금지자로 판정하거나 이 값만으로 현행 허용음까지 확정하면 안 된다.

[kHangul](https://www.unicode.org/reports/tr38/#kHangul)의 E는 교육용, N은 인명용 독음 출처 표시다. 두 속성 모두 provisional이며 법원 현행 전수 대조를 대신하지 않는다. 후보 생성·누락 탐색의 보조 자료로는 쓸 수 있다. KRName 페이지가 제공하는 [Yasuoka 텍스트](https://unicode.org/ivd/krname/yasuoka-20150122.txt)도 2015 판본에 기반하므로 최신 원본이라 부르지 않는다.

이 조사에서 새롭게 수록·뜻을 확인한 것은 5자다. 200자 원본 후보를 추출·검토했다고 보고하지 않는다. 확보한 PDF는 후속 시각 검토를 확장할 실제 자료이며, 기계 추출 불가 문제와 자형–독음 시각 검증 가능 여부는 분리한다.

## 불필요한 적격 차단을 만들지 않는 기준

실제 이름의 자연스러움은 조합 단계의 순위 조정 요소다. 특정 글자로 자연스러운 이름을 아직 만들지 않았다는 이유만으로 글자 적격을 미통과 처리하지 않는다. 허용음·자형 불일치와 근거 없는 오행 분류는 개별 후보를 막지만 원획 부재는 수리 참고 풀이만 막는다. 확인한 명확한 자형의 시각 검증에 공식 Unicode 일괄파일 확보를 추가 필수 조건으로 덧붙이지 않는다. 단 동자·이체자 식별이 실제로 모호한 개별 문자는 그 모호성을 남긴다.

후속 편집 판단: 직접 작성한 짧은 뜻풀이와 명시적인 의미 기반 배속을 갖춘 垠·堉·培는 이 2024 판본 자료의 초기 개별 후보로 채택한다. 圭·垣는 단일 오행 배속이 미확정이므로 보류한다. 자연스러움·분위기의 우선순위는 아직 부여하지 않았다. 기존 17자·18쌍과 합치면 초기 후보 20고유자·21쌍이며, 최종 사주 추천의 성공이나 200자 검토 완료를 뜻하지 않는다.
