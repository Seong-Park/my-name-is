# DeepSeek 서버 호출·토큰 계수 개발 검증

이 검증은 실제 출생정보나 명리 추천의 성공 증거가 아니다. 한 개의 개발용 문장 자료(한글 ‘가상’, 한자 假想, 실제 추천 아님 표시, 성인 연령대)를 사용한 최초 호출과 허용된 1회 재시도다. 출생정보·현재 이름·쿠키·후보 ID를 DeepSeek에 보내지 않았다. 프런트 stories 라우트는 여전히 비활성이다.

## 실제 관측

| 항목 | 최초 | 재시도 |
| --- | --- | --- |
| 공급자 생성 시각 UTC | 2026-09-30 15:58:47 | 2026-09-30 16:00:43 |
| 공식 chat template 로컬 토큰 | 395 | 395 |
| API 입력 토큰 | 419 | 419 |
| 차이 | +24 | +24 |
| API 출력 토큰 | 114 | 131 |
| 문단 계약 | 실패 | 통과: 58·57·58 코드 포인트 |
| 원장 비용 nano-USD | 131250 | 103818 |

최초 응답은 usage가 확인됐으나 출력 계약을 통과하지 못해 STORY_INVALID로 확정 실패 정산했다. 당시 검증기는 세부 실패 이유를 반환하지 않아 정확히 어느 출력 조건이 실패했는지는 확인하지 못했다. 이후 본문 없이 진단 가능한 형식/완료/문단 길이/내부 줄바꿈 코드를 추가했다. 같은 분석·후보의 attempt 1은 성공했고 더 재시도하지 않았다. 총 비용은 $0.000235068, 예약 잔액은 0이다. 원장의 실제 호출 기록은 지우지 않았다.

재시도 문장을 직접 확인했다. 가상임을 밝히고 성인의 일상적 상상·선택을 서술하며 실제 인생 사건·재산·건강·개명 효과를 단정하지 않는다. 실제 이름/한자 의미와 검증된 명리 근거가 결합된 문체 평가, 어린이·청소년 평가와 브라우저 종단 검증은 남아 있다.

## 자료와 구현

- [DeepSeek 공식 토큰 안내](https://api-docs.deepseek.com/quick_start/token_usage/)에서 연결한 [V4 tokenizer](https://cdn.deepseek.com/api-docs/deepseek_v4_tokenizer.zip)를 사용했다. Python 원격 코드는 실행하지 않았다.
- tokenizer.json SHA-256: `89085f12ef79460ac5f66d1119325ddfc694b4ab209d80bbd81d35f081dc9614`. 원본은 Git 제외 `.cache/deepseek_v4_tokenizer`에 있다.
- 공식 파일의 system+user chat template 분기를 [Hugging Face Tokenizers.js](https://github.com/huggingface/tokenizers.js)로 계산했다. 한글·한자·JSON·역할 구분 토큰이 포함된다. 글자 수를 토큰 수 대신 쓰지 않는다.
- [공식 API 계약](https://api-docs.deepseek.com/api/create-chat-completion/)에 따라 deepseek-flash, thinking disabled, JSON object, max_tokens 1024, 비스트리밍, 30초 제한을 적용했다. SDK/자동 재시도는 없다. 수동 개발 검증의 attempt 1만 별도로 실행했다.
- [공식 요금](https://api-docs.deepseek.com/quick_start/pricing/)의 peak 시간 밖이므로 cache-hit 3, cache-miss 150, output 600 nano-USD/token으로 정산했다. API usage의 캐시 적중/미적중을 분리했다.

두 번의 동일 입력 계수는 일반적인 API overhead 상한을 증명하지 않는다. 추가 근거 문자열·연령대의 계수 대조와 보수 여유값/이탈 시 차단을 연결하기 전 제품 AI를 켜지 않는다. 비용 원장·서명·검증된 추천 재계산과 라우트 통합 역시 미완료다.

## 추가 실측과 서버 연결

앞 절은 최초 두 호출 당시의 기록이다. 이후 별도 출생정보 없이 두 문장 검증 자료를 추가했다. 실제 추천이나 개인 기록으로 표시하지 않는다.

| 항목 | 한국어·한자, 0–5 | 긴 근거·확장 한자·JSON 이스케이프, 13–18 |
| --- | --- | --- |
| UTC 생성 시각 | 2026-09-30 16:55:15 | 2026-09-30 16:55:26 |
| 로컬 / 실제 입력 토큰 | 401 / 425 | 2311 / 2335 |
| 차이 | +24 | +24 |
| 출력 토큰 | 132 | 138 |
| 출력 계약 | 성공, 58·54·59자 | INVALID_STRUCTURE 실패 |
| 비용 nano-USD | 124134 | 376602 |

영유아 문장을 직접 읽었다. 가상임을 명시하고 숲·샘 뜻, 보호자·놀이·잠 장면을 사용한다. 직장·결혼·개명 효과나 실제 개인 과거를 주장하지 않는다. 긴 자료의 응답은 구조 검증 실패로 정산했으며 자동 재시도하지 않았다. 원문을 저장하지 않는 실패 정책상 세부 원문 구조는 이후 복원하지 않는다.

실제 DB 읽기 전용 집계: 호출 4, 성공 2, 실패 2, 예약 0, 비용 **735804 nano-USD = $0.000735804**, ai_halted false. 유료 기록을 유지했다. 출생 mock 데이터는 추가하지 않았다.

세 가지 서로 다른 입력, 총 네 응답에서 +24를 관측했다. 동일 두 역할·JSON 모드·현재 prompt와 고정 tokenizer에 운영 여유 104를 더한 **128 토큰 여유**를 적용했다. `validateStoryTokens`는 로컬 계산+128이 3000을 넘으면 422로 거절한다. 이는 유한한 실측에 근거한 운영 상한이며 미래 모델/프롬프트 변경에도 성립하는 공급자 보증은 아니다. 모델/프롬프트 변경 때 재검증하고, 응답 usage가 계산 상한을 넘거나 출력이 1024를 넘으면 실제 비용을 정산하면서 원장 ai_halted를 설정해 신규 호출을 중단한다.

제품 서버는 검증된 공개 후보 뒤에 이 검사·예약·dispatch·전송·정산을 연결했다. 로컬 전송/DB 대체 검사로 성공, 구조 실패, 통신 불명, 적용 요금 불명, 계수 이탈, 정산 장애를 확인했다. 실제 서버에서는 아직 공개 후보가 없어 403으로 막히며, 출생정보→추천→회상문 전체 성공 검증은 남아 있다. 원장 초기 통합 검증과 이번 대체 검사를 혼동하지 않는다.

## 실제 추천 후보 호출은 교정 실험과 별도

실제 역법으로 공개된 두 후보의 최초/수동 재시도 각 1회(총4회)는 모두 형식 실패였다. 최신2건은 INVALID_JSON, 마지막 건은 빈 문자열·코드 블록·BOM이 아닌 문법 오류다. 이 기록을 위의 문장 검증 성공2건과 혼동하지 않는다. 현재 전체 원장 집계는 8회/성공2/실패6, $0.001301892, 예약0이며 원장을 보존했다. 자동 재시도는 없다.
