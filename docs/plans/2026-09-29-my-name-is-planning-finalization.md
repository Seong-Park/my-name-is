## 수행 원칙

기획·판단·리뷰는 `gpt-6-astra`, reasoning `medium`으로 수행한다. 코드 구현 단계가 발생하면 `gpt-6-luna`, reasoning `medium` 하위 에이전트에 맡긴다. 이번 작업은 문서만 변경하므로 제품 테스트·빌드를 수행하거나 통과했다고 주장하지 않는다. 명리 규칙·한자 자료를 임의 값으로 완성 처리하지 않는다. 사용자 승인 권한의 위임은 사실 검증을 대체하지 않는다.

## 완료 기록

2026-09-29 문서·ADR 확정 작업을 완료했다. 제품·도메인·아키텍처 작성과 독립 교차 리뷰를 `gpt-6-astra / medium`으로 수행했다. 리뷰에서 API의 과금 상태 분류 P2 한 건을 발견해 수정했다. 공급자 실행·usage가 확인된 응답 검증 실패는 실제 비용을 정산한 `failed`로 처리해 슬롯을 해제하고, 실행·청구 여부가 불명확한 경우만 `uncertain`으로 유지한다. 독립 리뷰 담당자가 수정과 종료 확인 시각에 따른 슬롯 집계의 일치를 확인했다. ADR 0010·0011은 accepted다. 코드 구현을 수행하지 않았으므로 Luna 구현 에이전트는 이번 작업에서 호출하지 않았다.

문서 상대 파일 링크와 행 끝 공백 검사에서 오류가 없었고, `git diff --check`도 통과했다. 새 문서는 untracked 상태이므로 Git diff 검사와 별도로 파일 내용을 검사했다. 제품 코드는 변경하지 않았고 테스트·빌드·모바일 실행 검증·배포는 하지 않았다.

신강·신약·네 취용 방법·최강 오행의 개별 조건표, 검토된 추천 한자 목록, 원획·수리 대조와 실제 출시 검증은 명시된 선행 작업이다. 제품·API·아키텍처 결정 확정과 실제 엔진·데이터 납품 완료를 구분한다.
