# 독립 프로젝트 분리

승인: 사용자는 `C:\workspace\my-name-is`로 MVP를 분리하고 필요한 DB는 원본을 보존해 복사하도록 요청했다.

1. `mvp/` 문서를 새 프로젝트의 `docs/`로 이동하고 MVP 전용 자료 검사 스크립트를 이동한다.
2. 재사용하는 bazi-domain, bazi-rules, bazi-engine의 소스·설정·기준 사례를 복사한다. 독립 workspace 설정만 작성하고 제품 앱은 추가하지 않는다.
3. 한자 사전, 두 수리표, 이름 제외 목록을 복사한다. 기존 PostgreSQL 계정·출생정보 저장소와 연결 비밀은 복사하지 않는다. MVP 비용 원장은 아직 구현 전이다.
4. 문서가 인용한 기존 코드·문서를 출처 스냅샷으로 보존하고 상대 링크를 갱신한다. 참고 코드와 실행 패키지를 구분한다.
5. 복사 파일의 SHA-256과 원본 경로·Git 기준점을 기록한다. 이동 후 문서 링크, 자료 검사 및 원본 DB 보존을 확인한다.

검증 범위는 이동 무결성과 문서·자료 연결이다. 앱 구현, 의존성 설치 및 달력 계산 검증 완료를 뜻하지 않는다. MyLife의 미완료 의존성 복원 상태를 새 프로젝트로 복사하지 않는다.
