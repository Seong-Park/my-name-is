# 나의 이름은: 별도 Next.js 앱과 한 사람의 브라우저 기록

승인 근거: 2026-09-29 사용자의 추가 승인 없는 자율 확정 위임에 따라 채택했다. GPT-6-Astra medium의 제품·도메인·API·ADR 교차 리뷰와 발견 사항 수정을 완료했다. 실제 제품 구현·배포 완료를 뜻하지 않는다.

2026-09-29. [MVP 기획](../specs/2026-09-29-my-name-is-mvp-design.md)의 익명 모바일 웹을 별도 `apps/name-web` Next.js App Router·React·TypeScript 앱으로 구현한다. 입력·결과·회상문은 한 사람의 마지막 완료 결과를 `localStorage` 한 키에 저장하고, 서버에는 개인 기록을 저장하지 않는다. 기존 `apps/web`의 3D 광장이나 `apps/bazi-web`의 비회원 저장·로그인 흐름을 합치면 서로 다른 저장 정책과 출시 범위가 결합되므로 별도 앱을 택한다.

## 구현 경계

- `app/`은 페이지와 Route Handler, `components/`는 입력·결과 표현, `lib/contracts/`는 공개 DTO·검증, `lib/client/`는 브라우저 기록, `lib/server/`는 계산·추천·AI·운영 DB 책임으로 시작한다. 범용 상태관리·새 디자인 시스템·별도 프런트 서버를 만들지 않는다.
- 화면 상태는 React 상태로 관리한다. 입력 초안은 메모리, 완료 기록은 `name-web:last-result:v1`에 `{schemaVersion, revision, completedAt, input, analysis, stories}` 단일 JSON으로 보관한다. 이름·출생정보를 주소·검색 파라미터·공유 URL에 넣지 않는다.
- 정상 완료에는 두 유형 모두 보류인 분석도 포함한다. 완료 응답을 검증한 뒤 입력과 결과를 함께 교체한다. 통신·계산 실패는 이전 기록을 유지한다. 회상문을 기다리지 않고 이름과 근거부터 저장한다.
- `setItem` 실패 시 새 결과는 현재 화면에서 볼 수 있지만 ‘이 브라우저에 저장되지 않음’과 재시도를 표시한다. 저장됐다고 알리지 않는다. 읽기·파싱 실패나 지원하지 않는 스키마는 자동 해석·자동 삭제하지 않고 복원 불가 안내와 사용자가 지우는 동작을 제공한다. 초기 버전에는 범용 migration 체계를 만들지 않는다.
- 늦게 온 응답은 `revision + analysisId + candidateId`가 현재 기록과 일치할 때만 붙인다. 새 분석·전체 삭제·다른 탭의 `storage` 변경마다 진행 중 요청을 취소하고 revision을 바꾼다. 네트워크 취소가 공급자 과금 취소를 보장하지 않는다는 점은 서버 계약으로 처리한다.
- 여러 탭 쓰기는 같은 origin의 Web Locks로 짧게 직렬화하고 잠금 안에서 최신 revision을 재확인한다. Web Locks를 지원하지 않는 환경에서는 영속 기록 수정을 끄고 현재 탭의 메모리 결과만 제공한다. 단순 read-compare-write를 원자적이라고 가정하지 않는다.
- 명리 엔진·전체 한자 사전·비공개 후보·비밀키·DB 클라이언트는 서버 전용이다. 서버 전용 import 경계를 빌드에서 검사하며 브라우저에는 공개 DTO만 전달한다. 회상문은 일반 텍스트로 렌더링한다.
- 화면 상세·접근성·카카오 공유는 MVP 화면 명세를 따른다. 별도 결과 공유·계정 동기화·성공 회상문 재생성은 추가하지 않는다. 개인정보 없는 시작 URL만 공유한다.

## 버전과 현재 상태

현재 두 기존 앱은 Next.js `14.2.3`, React `18.3.1`을 선언한다. `apps/name-web`은 아직 없으며 이번에는 생성하지 않았다. 새 앱은 구현 시점의 **Next.js 16 Active LTS 최신 보안 패치와 그 릴리스가 요구하는 React·Node 버전**을 정확한 lockfile로 고정한다. 2026-09-29 확인한 [지원 정책](https://nextjs.org/support-policy)은 14.x를 지원 종료로 표시하며, [2026-08 보안 공지](https://nextjs.org/blog/august-2026-security-release)는 16.3.3과 15.5.24 수정판을 안내한다. 16.3.3은 확인한 최소 수정 사례이지 앞으로도 최신이라는 고정값이 아니다. 구현·배포 전 최신 공지를 다시 확인하고 개발 환경에도 적용한다.

기존 앱 전체 업그레이드를 이 MVP에 섞지 않는다. 새 앱에 기존 취약 버전을 복사하는 것은 허용하지 않는다. 비용과 복잡성은 단일 JSON 기록으로 줄이지만 브라우저 데이터 삭제·기기 변경·브라우저별 저장 격리로 복구가 안 되는 한계는 안내한다. 화면에 남은 과거 결과는 저장 당시 자료·공개 설정의 snapshot이며 이후 설정이 바뀌어도 원격 삭제할 수 없다.

공개 API·저장 버전·오류·재시도는 [API 및 운영 계약](../specs/2026-09-29-my-name-is-api-contract.md), 서버 책임은 [서버 ADR](0011-my-name-is-backend.md)을 따른다. ADR 채택은 구현·모바일 검증·배포 완료를 뜻하지 않는다.
