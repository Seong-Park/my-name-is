# 시간 미상 완전 원국과 추천 합의 — 2026-10-03

확정 PRD §6·§11, 핵심 규칙 §2.6의 미완료 구현을 채운다. 새 정책이나 새 시연 인물은 추가하지 않는다.

1. 기존 역법 정규화와 경계 분할을 재사용한다. 절입 오차의 양끝과 태양시 시진 경계±균시차 오차에서도 분할한다. 실제 같은 UTC 시각에서 가능한 연월 쌍과 일시 쌍만 결합하며 전체 날짜의 기둥별 Cartesian product를 만들지 않는다.
2. 원래 unknown/partial/hour unavailable 상태는 보존하고 서버 내부 완전 후보를 별도로 반환한다. 후보 집합은 공학적 공급자 오차 예산 안에서의 포괄성이며 역사적 정확도를 새로 보증하지 않는다.
3. 각 후보에 기존 검토 규칙을 적용한다. 모든 후보가 지원되고 목표가 같을 때만 허용 오행 교집합을 추천에 사용한다. 하나라도 미지원·불일치면 보류한다. 현재 제한 규칙 때문에 unknown 사례가 계속 보류될 수 있지만 원국 검토 자체를 건너뛰지 않는다.
4. 기둥 연동·23시·입춘·오차·민간 날짜의 제외 끝점·DST 후보를 회귀 검사한다. 앱의 unknown 보류와 exact 기존 성공을 보존하고 패키지/앱 테스트·타입·빌드를 수행한다.

책임: bazi-engine 경계 분할/완전 후보 계산; name-web 계산 어댑터/규칙 합의. 공개 DTO에 원국 후보나 숨긴 추천을 추가하지 않는다.

구현 결과: 완전 후보 열거/합의 연결, 경계 회귀 10개 통과. 초기 역법 전체 478개·앱43개 검사 통과 후 6개 추가 경계를 검증했다. 두 패키지 타입·앱빌드 통과. 실제 서버 기존 겨울 exact(3후보,well_matched)/unknown(보류) 확인. 공급자 오차 예산과 원래 partial 상태 유지. 새 시연/유료 호출 없음. 광범위한 명리 조건군·한자 검토·대표 제공률 등 상위 목표는 계속 미완료다.

최종 변경 상태에서 역법484개·앱43개 전체 검사 재통과.
